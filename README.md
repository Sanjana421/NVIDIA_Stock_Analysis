# 📊 NVIDIA Stock Analysis Dashboard

An interactive Power BI dashboard designed to explore **NVIDIA's stock performance, volatility trends, and risk patterns** through dynamic visualizations and KPIs. This project focuses on translating historical stock data into actionable insights using time series analytics, technical indicators, and synced interactivity.

---

## 🚀 Key Features

### 🟢 **Page 1: Stock Overview**
- **Line Chart** of NVIDIA's Close Price, 50-Day Moving Average, and 200-Day Moving Average
- **KPI Cards**:
  - 📈 Current Price
  - 🔼 YTD Return
  - 🌟 All-Time High
  - 📦 Average Volume (30-Day)
- **Date Range Slicer** for focused analysis
- **Synced interactivity** between visuals and with Page 2

---

### 🔵 **Page 2: Volatility & Risk Insights**

- **KPI Cards**:
  - ⚡ Average Volatility (YTD)
  - 🔺 Highest Volatility Day
- **Line Chart** of 30-Day Rolling Standard Deviation – visualizing short-term risk spikes
- **Heatmap Matrix** of Monthly × Yearly average daily % change — color-coded by volatility level
- Fully synced with Page 1 for consistent timeline navigation

## 🛠 Tools & Technologies

- [Power BI Desktop](https://powerbi.microsoft.com/desktop)

- Custom themes and formatting for UX polish

---

## 🎯 Insights Discovered

- NVIDIA’s price trends show clear alignment between moving average crossovers and market momentum
- Historical volatility tends to spike during earnings seasons and tech sector turbulence
- Certain months show recurring high-volatility behavior across years (especially Q4)

## 🔄 How to Use

1. Clone or download the repository
2. Open `NVIDIA_Stock_Analysis.pbix` in Power BI Desktop
3. Interact with slicers, tooltips, and visual navigation
4. Export to PDF, publish to Power BI Service, or embed in a portfolio
